## Описание/Description 

> Учебный декстопный проект по получению практических знаний языка программирования С#, технологии WPF , реализации паттерна MVVM, работы с SQL Lite.
> Приложение является системой введения конспектов и докладов.  

> An educational desktop project to gain practical knowledge of the C# programming language, WPF technology, implementation of the MVVM pattern, and working > > with databases SQL Lite. The application is a system for entering notes and reports.

## Задача/Task

> Реализовать графический интерфейс приложения, с которым будет удобно вести заметки внутри конспектов. Уметь задействовать базу данных.

> Implement the graphical interface of the application, which will be convenient to keep notes inside the notes. Be able to use the database.
